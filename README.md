# ML-Project

This project builds an end-to-end supervised ML pipeline to predict whether 
an employee is likely to leave a company (attrition). Using a synthetic HR 
dataset with 1,470 employees and 30 features, the pipeline covers data 
preprocessing, feature engineering, model training, hyperparameter tuning, 
and evaluation. The best model (Random Forest) achieves ~82% accuracy on 
the test set, with custom engineered features ranking among the top predictors.
